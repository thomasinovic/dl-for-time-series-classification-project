# Deep learning for time series - Project
__Task__: Adapt a foundation model for classification

We choose to adapt mutliple foundation models for time series classification, namely Mantis, Chronos, TS2VEC, Moment and TimesFM. The notebooks for fine-tuning these models can be found in the `src/notebooks` directory.

Some logs can be found in a subfolder of `src/notebooks`.

## Setup
Using uv, you can install the required dependencies with the following command:

```bash
uv sync
```
